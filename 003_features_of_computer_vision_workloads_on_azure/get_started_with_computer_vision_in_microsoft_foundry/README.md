## Get started with computer vision in Microsoft Foundry

---

### Foundry Tools for computer vision

Within Azure Vision, there are services that handle specific sets of tasks including:

1. **Azure Vision Image Analysis service**: Detects common objects in images, tags visual features, generates captions, and supports optical character recognition (OCR);
2. **Azure AI Face service**: Detects, recognizes, and analyzes human faces in images. Provides specific models for facial analysis that extend beyond what is available with image analysis;

---

### Understand Azure Vision Image Analysis capabilities

1. Describing an image with captions;
2. Detecting common objects in an image;
3. Tagging visual features;
4. Optical character recognition;
5. Training custom models;

---

### Understand Azure Vision's Face service capabilities

1. Facial detection;
2. Facial recognition;
